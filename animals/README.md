# Animal photos

Each animal has a real photo with a transparent background, from Wikimedia
Commons (see CREDITS.md). To swap one, replace the file, keeping the name (PNG, about 600×600 px or larger, square-ish). If a
photo is missing, the game shows the animal's emoji instead.

Good free sources: Wikimedia Commons, Pixabay, Unsplash, Pexels. To cut out
the background, use the "Remove background" option (long-press a photo in the
iOS Photos app → Copy Subject, or remove.bg / Canva). Note each photo's
source and licence in CREDITS.md.
